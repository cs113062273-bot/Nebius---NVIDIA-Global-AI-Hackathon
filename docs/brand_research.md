# Brand research

2026-10-20: rejected A11yProof, AccessPatch and AccessAI (occupied accessibility brands). Rejected Keystitch (existing App Store product) and Pathloom (multiple existing products and GitHub projects).

Rejected Tablume after broader search found a software trademark application and Chrome extension. Rejected Tablyth because the name also appears in an established fictional universe.

Selected working product name **Tabstitch**: repair a broken path, stitch the evidence together. Exact quoted web, GitHub, Devpost, npm and trademark searches on 2026-10-20 found a personal StoryGraph handle and unrelated sewing/patent text, but no relevant accessibility/software product collision. These were search-engine checks, not authenticated registry or legal clearance. Search absence is not proof of availability. No domain purchased. Recheck before submission.
