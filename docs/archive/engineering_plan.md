# Engineering plan

Build a local-first Node application with an accessible browser workbench. One language keeps the deterministic browser engine, schemas and API together. No database service or GPU dependency. Local artifact storage; bundled static applications need no install scripts. Public mode only runs allowlisted fixtures.

1. Establish current contract, competitor overlap and honest positioning.
2. Implement strict journey/assertion schemas, frozen oracle hashes, four verdicts, validated states.
3. Build isolated Playwright runs: real keys, bounded targeting, checkpoint screenshots, ARIA/CDP AX, axe categories, focus trace, runtime diagnostics, postconditions and environmental probes.
4. Add source ranking and bounded isolated text edits with preimage hashes. No model commands. Build/parse and functional checks before differential gate.
5. Add real Token Factory client: authenticated catalog, explicit sponsor-credit guard, persistent budget reservation, bounded structured response, provenance, no silent offline substitution.
6. Ship an explicitly labeled offline reference-patch replay to exercise the verifier without claiming AI repair. Negative controls include cosmetic no-op, broken functionality, source injection and oracle/environment drift.
7. Implement visible workbench timeline, evidence, focus graph, patch, same-journey proof and downloadable hashed bundles.
8. Run unit, integration, browser, security, mutation benchmark and UI axe checks. Record denominators and provenance. Add historical cases only with verified revisions/licenses; do not relabel synthetic cases as historical.
9. Audit, red-team, independently reread critical flows, fix findings, rerun, clean-copy setup. Prepare judge documentation and deployment configuration.
10. Only claim live inference, historical recovery, public deployment or holdout results after execution. External credentials/access may remain human actions; keep all other work executable now.
