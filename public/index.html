    SCOPE IS PART OF THE RESULT

    Specific evidence. Honest limits.

    What execution can show

    Actual keyboard transitions, explicit task outcomes, accessibility-tree semantics, automated WCAG rule results and the frozen functional checks. A repair is accepted only after differential replay.

    What still needs people

    Real screen-reader experience, meaning and usefulness of content, cognitive usability and complete accessibility conformance. Reflow probes use CSS viewport equivalents, not actual browser zoom.

    Where Nemotron belongs

    NVIDIA Nemotron through Nebius Token Factory can diagnose focused evidence and propose bounded source edits. It cannot change the journey oracle or grant itself a passing verdict.

    Zero axe violations does not mean full accessibility. AX snapshots are not real screen-reader testing. This build is a local research workbench with curated synthetic applications.
