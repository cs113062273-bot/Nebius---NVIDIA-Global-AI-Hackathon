Repair the task.
Keep the outcome.

Tabstitch fixes keyboard and form bugs in web components. NVIDIA Nemotron on Nebius Token Factory writes the patch. A real browser then replays the user's task, and the patch is accepted only if the task passes, the submitted data stays the same and no guarded behaviour breaks. It was tested on real bugs that the maintainers of Bootstrap, GOV.UK Frontend and other libraries fixed by hand.

    What this pass does and does not establish
    Each recording verifies only its frozen journey and recorded conditions. It does not establish a repair success rate, full WCAG conformance or real screen-reader support.
